# Geri Dönüşüm Uygulaması

Sosyal Sorumluluk dersi projesi. Şehirdeki geri dönüşüm kutularını haritada gösteren,
kutu doluluk/hasar durumunun bildirilebildiği ve geri dönüşüm yapan kullanıcıların
puan kazanıp sıralamaya girdiği bir Android uygulamasıdır.

## Teknolojiler
- Kotlin
- Jetpack Compose
- Firebase (Authentication, Cloud Firestore)

## Özellikler (planlanan)
- Geri dönüşüm kutularını haritada görme
- Kutu doluluk ve hasar bildirimi, geliştirme önerisi gönderme
- Geri dönüşüm türüne göre puan kazanma
- Puan sıralaması ve ilk 3 kullanıcıya duyarlı vatandaş belgesi
